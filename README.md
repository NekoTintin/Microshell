# Microshell
Un Microshell pour 42 (exam rank 04)

## Informations
Il n'y a que le minimum nécessaire, pas de code retour, pas de restauration de STDIN.

## Compilation et tests
- Utilisez ```bash compile.sh``` puis ```./microshell```
- Pour tester avec Valgrind: ```valgrind --track-fds=all ./microshell```
